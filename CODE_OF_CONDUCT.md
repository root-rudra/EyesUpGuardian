# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help. Disagree about code, not about people.

## What's expected

- Discuss ideas, code and trade-offs — not the person proposing them.
- Accept that "no" is a complete answer to a feature request, and that a maintainer's time is a gift.
- Keep it on topic: this is a project about keeping a Mac awake, not a general forum.
- Respect privacy. Don't post other people's personal information, and don't paste anything from a
  machine you don't own.

## What isn't

Harassment, personal attacks, discrimination, sexual attention or imagery, deliberate intimidation,
sustained disruption, or publishing anyone's private information.

## Reporting

If someone's behaviour is a problem, message the maintainer through GitHub (@root-rudra). Reports are
handled privately. The maintainer may edit, hide or delete comments, close discussions, or block
accounts that break these rules — with an explanation where that's possible, and without one where
explaining would make things worse.

## Scope

This applies in issues, discussions, pull requests, commit messages and anywhere else this project
is being represented.

*Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org), kept short
so that it actually gets read.*
